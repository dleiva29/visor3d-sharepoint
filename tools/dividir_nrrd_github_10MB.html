Dividir NRRD para GitHub Pages

Funciona localmente: el archivo no se envía a ningún servidor. Cada fragmento tiene un tamaño máximo de 10 MB (10.000.000 bytes) y se guarda sin comprimir ni alterar sus bytes.

Un NRRD de 120 MB generará aproximadamente 12 fragmentos. Los navegadores pueden pedir permiso para descargar varios archivos. Autorízalo para esta página local. Mantén todos los fragmentos juntos en GitHub.
